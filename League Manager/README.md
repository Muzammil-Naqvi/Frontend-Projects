# ⚽ Football League Manager

## 📌 Description

A full-stack web application to manage football leagues, teams, and match data with a database backend.

## 🚀 Features

* Team and player management
* Match scheduling and results tracking
* Database integration
* Interactive frontend

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Database (SQL)

## ▶️ How to Run

1. Open the frontend files in browser
2. Connect to database backend
3. Run server (if applicable)

## 📷 Future Improvements

* Add authentication system
* Improve UI/UX
* Add live match updates
